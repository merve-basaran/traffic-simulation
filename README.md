# Traffic Simulation

A traffic simulation implemented in C++ using Object-Oriented Programming principles, developed as part of the RWTH Aachen University Informatik Praktikum.

## Features
- Vehicle classes: PKW, Fahrrad (car, bicycle)
- Road and intersection (Kreuzung) management
- Dynamic driving behaviors: Fahren, Parken, Losfahren
- Polymorphism and inheritance-based design

## Technologies
- C++
- Object-Oriented Programming
- Eclipse IDE
